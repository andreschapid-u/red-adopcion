# Security policy

## Supported versions

Red de Adopción is a static site. Only the latest deployment published at
<https://andreschapid-u.github.io/red-adopcion/> is supported. There are no
versioned releases of the web client.

## Reporting a vulnerability

Please report security issues privately to **chapid302@gmail.com** with the
subject `[SECURITY] Red de Adopción`. Do not open a public issue.

Include:

- Affected URL, endpoint, or repository.
- Steps to reproduce and the expected vs. actual behavior.
- Impact you believe it has.
- Any proof of concept, without accessing data that is not yours.

## Scope

In scope:

- The static site and its client-side code.
- The read-only Apps Script API and its deployment.
- The build and deploy pipeline in this repository.

Out of scope:

- GitHub, Google, WhatsApp, Instagram, or any other third-party service.
- Social engineering, spam, or physical attacks.
- Denial of service, volumetric testing, or automated scanning that degrades
  the service.
- Reports that only show missing security headers on GitHub Pages without a
  demonstrated impact.

## What to expect

- Acknowledgement within 3 business days.
- Triage and severity assessment within 5 business days.
- A fix or mitigation plan for confirmed high-severity issues within 30 days.
- Credit in the fix commit if you want it.

## Safe harbor

We will not pursue legal action for good-faith research that follows this
policy. Do not access, modify, or exfiltrate data that is not yours, do not
degrade the service, and give us reasonable time to fix the issue before any
public disclosure.
